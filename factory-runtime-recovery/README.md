# Spectre one-shot recovery

PR #2 remains draft/open. No merge, deployment, Factory Completion PASS or Cockpit Release PASS is claimed.

Distribution is BLOCKED_PENDING_WINDOWS_QUALIFICATION. This revision is not a Director trial package. See INSTALLER_AUDIT_20260921.md for ending condition B and unresolved blockers.

`START_FACTORY_RECOVERY.cmd` is the internal self-contained launcher generated by `build_package.py --output-directory <internal-directory>`. One launch expands the package, checks byte hashes and native Windows preflight, collects safe machine evidence, conditionally repairs a confirmed HMAC-constructor pre-spawn failure, restarts the existing watcher once, observes the canary, displays liveness/terminal status and saves one return ZIP. Unknown or inconsistent evidence produces HOLD with no watcher replacement.

Expected hashes still refer to the exact installed v1 bytes. HMAC authentication remains before AES decryption. KEYS are not collected or changed; only the normal watcher retains its existing local DPAPI access. Failure and retry eligibility are separate; the canary gets one evidence-authorized retry. Any subsequent terminal/interrupted/ambiguous attempt stays visible and blocks further jobs.

The diagnostic returns fixed booleans, scalar codes, hashes and bounded status. No patient data, source, raw stdout/stderr or unrestricted logs are returned. Desktop/TanukiFactory_Result receives one result ZIP (JSON fallback if compression fails). This is option C/manual return, not automatic return completion. The status screen has a button for the actual existing result file; the wrapper selects it on terminal exit. Installer phase/class/line are returned without raw exception messages.

Persistent per-user Startup resumes the controller after the next natural restart/logon; it never reapplies the installer. It records reboot evidence but does not force a reboot or declare the ten Factory gates complete from a process being alive. Comic and FX remain blocked. Next-job transport/advancement and fully automatic authenticated result return are not implemented by this canary recovery package.

See COMPATIBILITY_AUDIT.md and SELF_AUDIT.json for AI-side checks and native checks deferred to the first controlled Windows launch. `Windows.Preflight.ps1` uses synthetic data only. No Windows executor was available in this Work; the previous Spectre package preflight PASS does not qualify this changed installer.
